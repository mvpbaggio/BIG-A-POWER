# BIG-A-POWER · A股指标引擎

**17 个通达信指标 → 5 组共振 → 趋势组主线 + 动量组闸门 + 净票转空（多空双强）**

A股波段指标引擎，用自建回测系统（真实费率 / next_open 成交 / 无未来函数 / 严格 7 窗样本外 WF）验证。

## 设计思路

引擎三层结构：

1. **指标打分层**：17 个通达信指标，每个输出 `-100 ~ +100` 信号分
2. **组共振层**：指标聚成 5 组（趋势/动量/波动/量能/形态），组内同向共振计分
3. **闸门 + 净票转空层**：趋势组作主线，确认组净票闸门放行，净票转空时输出对称卖出信号 → 多空双强

核心信号逻辑（趋势组主线 + 动量组闸门 + 双向对称）：

```python
s = gs["趋势组"].copy()                          # 趋势组共振分
net = _net(gs, ["趋势组", "动量组"])              # 确认组净票
s[net < 1] = 0.0                                 # 净票不足：不做多
negmask = (net <= -1) & (gs["趋势组"] < 0)        # 确认组转空
s[negmask] = -np.abs(gs["趋势组"][negmask])        # 对称卖出信号
```

买入信号 `s >= 25`，卖出信号 `s <= -25`，双向对称。

## 回测表现（signal 模式，回测系统，默认500只 seed=42）

> 修复了 2 处未来函数（`np.convolve(mode='same')`、`np.gradient` 中心差分偷看未来）+ signal_from_R 净票转空/幅值 bug 后，以下是**真实（无未来函数、无失真）**评估结果。
> 统一口径：同池 seed42 500只、evaluate_engine 权威评分（相对内置打100分基础）。

| 引擎 | 收益 | 7窗WF | 夏普 | 回撤 | 权威评分 |
|---|:---:|:---:|:---:|:---:|:---:|
| **BIG-A-POWER（本引擎, min_abs=10, sell_th=2）** | +94.1% | **+44.4%** | 0.30 | 30.7% | **99.771** |
| easy-tdx MyTT MACD | +94.3% | +36.1% | 0.32 | 20.4% | 99.939 |
| MACD金叉死叉 | +94.0% | +36.1% | 0.31 | 20.4% | 99.805 |

- **收益打平内置**（+94.1% vs +94.3%/+94.0%，差 <0.3%）
- ✅ **泛化7窗WF更强**（+44.4% vs +36.1%，样本外更稳）
- ⚠️ **回撤更大**（30.7% vs 20.4%）拖累夏普，综合评分略低于内置（99.77 vs 99.94）

> ⚠️ 幸存者偏差（当前存续股抽样）让绝对收益偏乐观；相对对比稳（同池内本引擎与内置 MACD 基本打平，泛化略优）。
> ⚠️ 这是**同池同口径的权威结果**。之前 README 的 +309.8%/99.12/+392.6% 是基于有 bug 信号/不同参数的虚高数字，已作废。
