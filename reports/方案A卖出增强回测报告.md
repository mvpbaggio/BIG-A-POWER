## 一、结论（先给答案）

**最优方案 = 方案A「净票转空」**（现有引擎最小改动，给趋势组信号加对称空头卖出维度）。

在 signal（有买有卖）模式下，收益翻倍 + 回撤减半 + 夏普翻倍，且 7 个样本外窗口全部为正（无亏损段），是唯一满足「卖出也变强、多空双强」且稳健的方案。

**为什么方案A最强：**
- 现有引擎 `net<1` 时信号归零（只买不卖）→ 空头行情空仓，利润全回吐，回撤 33.5%
- 方案A 把「净票转空」：`net<=-1` 且趋势组为负时，输出对称卖出信号 → 空头顺势锁利润
- 效果：回撤 33.5%→13.5%（减半），夏普 0.62→1.33（翻倍），收益 +316%→+538%
- 7窗样本外全正，说明不是过拟合（不是"挑同期最顺参数"的假象）

**方案B（参考最强卖引擎补卖出）反而不如：**
- 补了动量组死叉卖出，但把信号叠加复杂化，买卖冲突处理保守，收益反而被砍（+154%）
- 说明"参考别人卖出逻辑"不如"把自家信号做对称"，贴合引擎本身的共振才有加成

## 三、三种方案实现要点

### 方案A「净票转空」— 推荐 ✅
```python
def sig_A(gs):
    s = gs["趋势组"].copy()          # 趋势组共振分
    net = _net(gs, ["趋势组","动量组"])  # 确认组净票
    s[net < 1] = 0.0                  # 净票不足→不做多(原逻辑保留)
    negmask = (net <= -1) & (gs["趋势组"] < 0)  # 新增：净票转空
    s[negmask] = -np.abs(gs["趋势组"][negmask])  # 输出对称空头信号→驱动卖出
    return s
```
**改动量：只加 2 行**，贴合现有引擎（马尾：最小 diff）。`signal` 模式下卖出信号生效。

### 方案B「补参考卖出引擎」— 不推荐 ❌
买入照旧 gate_trmo，卖出叠加「动量组 ≤ -25」死叉信号。逻辑正确但叠加复杂化，买卖冲突处理保守，收益被砍。不如方案A的对称化干净。

### 方案C「吊灯止损增强」— trailing 模式全面失效 ❌
trailing 下三个引擎全亏（现有 -34% / A +1% / B -12%），说明**这套共振引擎不适合叠吊灯止损**——止损过敏感，频繁割肉吃不到趋势。signal（信号驱动卖出）才是正解。

## 四、关键认知修正

1. **现有引擎 long_only 和 signal 结果相同（都 +316.6%）**：因为现有信号 `net<1` 归零、无卖出信号，signal 模式天然退化成 long_only。这正是"只买不卖"的病根。
2. **方案A 在 signal 下才是真多空双强**（卖出信号 238084 个真正生效）；long_only 下它跟现有一样（本来就是只买）。
3. **trailing 模式对本引擎是错的出场方式**：震荡频繁触发 ATR 止损割肉，全亏。本引擎必须用 signal（信号驱动买卖）。
